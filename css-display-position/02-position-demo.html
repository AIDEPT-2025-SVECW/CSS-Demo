CSS Position – Student Friendly Demo

Scroll slowly and read comments in the code. Each colored box represents one CSS position type.

1️⃣ position: static (Default)

STATIC BOX
"I sit normally"

Static elements follow normal HTML flow. They ignore top, left, right, bottom.

2️⃣ position: relative

RELATIVE BOX
"I move from my seat"

Notice: Space is still reserved, but the box has shifted slightly.

3️⃣ position: absolute

ABSOLUTE BOX
"I sit anywhere"

This box is positioned relative to the container. It does NOT reserve space.

4️⃣ position: sticky

STICKY BOX
"Scroll me"

Scroll down. This box will stick to the top when it reaches it.

FIXED BOX
"I stay on screen"

🎉 End of demo! Try changing values in CSS and observe behavior.
