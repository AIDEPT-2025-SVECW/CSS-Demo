CSS Display Property Explained 🇮🇳

The display property controls how an element appears and behaves on a web page. Think of it as how things are arranged in real life.

1️⃣ display: block (Like Shops on a Street)

🏬 Each shop occupies the full width of the street. No shop can stand beside another.

🏪 Kirana Shop
🧺 Vegetable Shop
🥛 Milk Booth

2️⃣ display: inline (Like Words in a Sentence)

📜 Inline elements behave like text in a sentence.

Ram went to temple

3️⃣ display: inline-block (Like Chairs in a Row)

🪑 Chairs are placed side by side, but each chair has its own size.

🪑 Chair 1
🪑 Chair 2
🪑 Chair 3

4️⃣ display: none (Like Removing a Shop)

❌ The shop is removed completely. No space is left.

🏪 Open Shop
🚧 Closed Shop
🏪 Another Shop

5️⃣ display: flex (Like Items on a Shop Shelf)

🛒 Items are neatly arranged in one row.

🍪 Biscuits
🥤 Juice
🍫 Chocolate

6️⃣ display: grid (Like Apartment Layout)

🏢 Grid divides space into rows and columns.

🏠 House 1
🏠 House 2
🏠 House 3
🏠 House 4
🏠 House 5
🏠 House 6

🧠 Easy Exam Summary

  • block → Full width, new line
  • inline → Same line, no width control
  • inline-block → Same line + width control
  • none → Completely removed
  • flex → One-direction layout
  • grid → Row & column layout

Exam one-liner:
The CSS display property defines how an element is displayed and how it participates in the page layout.
