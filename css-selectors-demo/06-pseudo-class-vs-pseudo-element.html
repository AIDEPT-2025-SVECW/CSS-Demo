1️⃣ Pseudo-classes (Element State)

2️⃣ Pseudo-elements (Part of an Element)

Swachh Bharat Abhiyan aims to make India clean and open defecation free.

🧠 Easy Comparison for Exams

Pseudo-class:
Changes style based on STATE of element
Uses → :

Pseudo-element:
Styles PART of an element
Uses → ::

🔑 Memory Trick:
One colon → State
Two colons → Piece
