🇮🇳 CSS Selectors Demo

Below examples use Indian states to explain Element vs Class vs ID and which style wins.

Kerala (Only <div> element selector applies)
➜ Background: light blue
Karnataka (Element + Class)
➜ Class wins → orange
AP (Element + Class + ID)
➜ ID wins → light green
Tamil Nadu (Element + Class only)
➜ No ID rule → class wins → orange

🧠 Easy Rule to Remember

  • Element selector → Applies to all (weakest)
  • Class selector → Applies to group (stronger)
  • ID selector → Applies to one (strongest)

👉 When multiple styles apply to the same element:

ID > Class > Element

🧠 More specific selector always wins over a less specific one.
