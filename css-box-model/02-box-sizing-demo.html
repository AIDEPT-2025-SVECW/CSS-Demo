📦 CSS box-sizing – Understanding Box Model Size

Imagine a sweet box 🍬 with a fixed size. The question is:
Should padding and border be included inside the box size or added outside?

1️⃣ box-sizing: content-box (Default)

Content Box

Width = 300px (content only)
Padding + Border are added outside

🧠 Layman Meaning:
The sweet box size increases when we add padding and border.

🏠 Real-life Example:
Laddu size is fixed, but wrapper and box add extra size.

2️⃣ box-sizing: border-box (Recommended)

Border Box

Width = 300px (content + padding + border)

🧠 Layman Meaning:
Box size stays fixed no matter how much padding or border you add.

🏠 Real-life Example:
Sweet box has fixed outer size; laddu adjusts inside.

3️⃣ box-sizing: inherit

Parent (box-sizing: border-box)
Child Box

Inherits box-sizing from parent

🧠 Layman Meaning:
Child box follows parent's rule.

🧠 Easy Exam Memory

Value What width includes Easy Memory
content-box Content only Box grows bigger
