CSS Margin Collapse – Simple Indian Context Explanation 🇮🇳

Key Rule to Remember:
✅ Vertical margins (top & bottom) can collapse
❌ Horizontal margins (left & right) NEVER collapse

1️⃣ Vertical Margins Collapse (Top & Bottom)

Think of two places stacked vertically – like a Temple and a Sweet Shop on the same road.

🛕 Temple
margin-bottom: 40px
🍬 Sweet Shop
margin-top: 60px
What happened here?
• Temple has margin-bottom: 40px
• Sweet Shop has margin-top: 60px

❌ They did NOT add up to 100px
✅ Browser used the bigger margin → 60px

This behavior is called Vertical Margin Collapsing.

2️⃣ Horizontal Margins Do NOT Collapse (Left & Right)

Now imagine two shops side-by-side in a market: a Chai Stall and a Pan Shop.

☕ Chai Stall
margin-right: 40px
🚬 Pan Shop
margin-left: 60px
What happened here?
• Right margin = 40px
• Left margin = 60px

✅ Total space = 40 + 60 = 100px

Horizontal margins ALWAYS add up.
❌ No collapsing happens here.

🧠 Easy Exam Memory Trick

📏 Standing in a queue (vertical) → people overlap → margins collapse
🛍️ Walking side-by-side (horizontal) → space adds up → no collapse

One-line exam answer:
Margin collapsing affects only vertical margins (top and bottom), whereas horizontal margins (left and right) always add up normally.
