CSS Padding Shorthand Syntax 🇮🇳

Padding is the space between the content and the border of an element.
In Indian context, think of padding like the empty space between a house wall and furniture.

1️⃣ Padding with ONE value

🏠 Like keeping equal walking space on all sides inside a room.

padding: 20px;
Same space on all sides

2️⃣ Padding with TWO values

🛕 Like a temple corridor: more space on left & right for walking, same space on top & bottom.

padding: 20px 40px;
Top & Bottom = 20px
Left & Right = 40px

3️⃣ Padding with THREE values

🌸 Like Rangoli space: small space near the door, wide space on sides, more space at the bottom.

padding: 10px 30px 50px;
Top = 10px
Left & Right = 30px
Bottom = 50px

4️⃣ Padding with FOUR values

🧱 Like different spacing inside a compound wall on all four sides.

padding: 10px 20px 30px 40px;
Top → Right → Bottom → Left

🧠 Easy Memory Trick

🕰️ Think of a clock:

  • 1 value → all sides
  • 2 values → vertical | horizontal
  • 3 values → top | sides | bottom
  • 4 values → clockwise (TRBL)

Exam one-liner:
Padding shorthand allows setting spacing on all sides of an element using one to four values in a clockwise manner.
