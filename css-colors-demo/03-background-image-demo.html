🖼️ CSS Background Images – Indian Context

1️⃣ Basic Background Image (Temple)

Google 2026 Doodle as Background
background-size: cover
background-position: center

2️⃣ Background Repeat (Rangoli Pattern)

Rangoli pattern repeated like floor decoration
background-repeat: repeat

3️⃣ Contain vs Cover (Village Road)

contain shows the full image but may leave empty space. cover fills the area but may crop image.

background-size: contain
background-size: cover

4️⃣ Fixed Background (Festival Lights)

Scroll the page to see
background-attachment: fixed

4️⃣ Scrollable Background (Festival Lights)

Scroll the page to see
background-attachment: scroll

📝 Quick Student Summary

  • background-image → puts image behind content
  • cover → fills area (best for banners)
  • contain → shows full image
  • repeat → tile pattern
  • fixed → parallax effect
