🎨 HSLA Color Model – Indian Context

What is HSLA?

HSLA stands for:

  • H (Hue) → Color type (0°–360°)
  • S (Saturation) → Color strength (%)
  • L (Lightness) → Brightness (%)
  • A (Alpha) → Transparency (0–1)

HSLA is very useful when we want to show transparent colors like glass, overlays, shadows, or light effects.

HSLA Examples (Transparency in Action)

hsla(30, 100%, 60%, 1) → Indian Flag Saffron (No Transparency)
hsla(30, 100%, 60%, 0.5) → Same Saffron (50% Transparent)
hsla(120, 70%, 40%, 0.7) → Flag Green with slight transparency
hsla(330, 80%, 55%, 0.4) → Rangoli Color (More transparent)
hsla(45, 100%, 50%, 0.6) → Diya Flame Glow Effect

🧠 Easy Way to Remember (For Exams)

  • HSL → Choose the color
  • + A → Control visibility
  • Alpha = Glass effect

👉 Use HSLA when you want overlays, fade effects, highlights, or shadows.
