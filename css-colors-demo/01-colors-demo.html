🎨 CSS Color Codes Demo (RGB, HEX & HSL)

1️⃣ RGB Color Model (Red, Green, Blue)

RGB works like mixing lights. Each color value ranges from 0 to 255. More value means more brightness of that color.

rgb(255, 153, 51) → Indian Flag Saffron
rgb(255, 255, 255) → White (All colors fully ON)
rgb(19, 136, 8) → Indian Flag Green

2️⃣ HEX Color Codes (#RRGGBB)

HEX is just another way to represent RGB using hexadecimal numbers. It is commonly used in real-world projects and design tools.

#FF0000 → Traffic Signal Red
#FFCC00 → Festival Light Yellow
#000080 → Ashoka Chakra Blue

3️⃣ HSL Color Model (Hue, Saturation, Lightness)

HSL is easier for humans to understand because it follows a color wheel concept.

  • Hue: Color type (0° = Red, 120° = Green, 240° = Blue)
  • Saturation: Color strength
  • Lightness: Brightness
hsl(330, 80%, 55%) → Rangoli Pink
hsl(120, 60%, 40%) → Leaf Green
hsl(210, 70%, 50%) → Sky Blue

📝 Quick Summary for Students

  • RGB → Best when thinking in numbers (0–255)
  • HEX → Compact & widely used in projects
  • HSL → Best for adjusting brightness & shades easily
